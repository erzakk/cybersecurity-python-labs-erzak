# Лабораторна робота №2
**Варіант 6:** Аудитор надійності та масок словників паролів

## Опис роботи
У цій лабораторній роботі реалізовано два завдання:
1. **Завдання 1:** Система моделювання користувачів, безпечних сесій та аудиту на основі ООП. Паролі безпечно хешуються (PBKDF2 HMAC SHA-256 + salt), сесії мають таймаут (900 секунд), а всі події фіксуються в журналі аудиту через `Enum`.
2. **Завдання 2:** Консольна утиліта (CLI) для аудиту словника паролів. Файл обробляється через генератори для економії пам'яті. Використовуються регулярні вирази для визначення масок паролів (наприклад, "Усі малі літери", "Складний" тощо). Результат зберігається у форматі JSON.

## Структура проєкту
Тестові дані (словник паролів) знаходяться за шляхом: `labs/lab02/data/data_v06/passwords.txt`.
Звіт генерується у файл `mask_audit_report.json` у папку `data/`.
